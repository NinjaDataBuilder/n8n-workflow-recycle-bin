# n8n 2.44.5 maintenance candidate

This maintenance candidate pins the sidecar runtime to Node.js 22.23.4 and a multi-platform image digest. It keeps the direct, session-authenticated `/recycle-bin/` service and existing audit storage separate from optional editor overlays.

## Exact adapter generation

The Docker build reads four frontend inputs from the digest-pinned n8n 2.44.5 image, verifies their SHA-256 fingerprints, and generates the exact app/router, sidebar and workflow-menu overlays. An unknown input fails the build before any generated output is written. Native inputs and generated bundles are not committed to this repository or included in the source release archive. The build includes the generator instead.

The embedded view imports the verified public Vue `h()` export (`qd`) from `vendor-COD0pq0C.js`; it does not reuse the obsolete standalone Vue chunk or assume that a minified alias from another n8n version still means the same function.

### Root base-path rendering

The editor's raw app bundle contains five encoded base-path placeholders and one raw placeholder. n8n replaces these while serving JavaScript over HTTP; the sidecar static handler does not. After checking the original fingerprints, the generator explicitly renders this exact known shape for an n8n deployment mounted at `/`, then adds the route. It rejects an unknown placeholder count. Do not use this root-only adapter for an n8n subpath deployment. Compare the generated app to the native HTTP-served app plus the isolated route change; a raw-file fingerprint alone cannot establish browser-equivalent delivery.

A cookie-scoped diagnostic preview may be staged for the owner's existing authenticated browser without changing default editor assets. This is not global activation or compatibility promotion. Preview cookies carry no authentication authority, expire after 30 minutes, and must not replace n8n's own session checks. Cache reset, if required, clears only HTTP cache, never cookies or browser storage.

## Acceptance boundary

- Unit tests, exact-input generation and JavaScript syntax checks are automated source gates.
- Running-image checks, non-root PID verification, direct HTTPS access and sessionless `401` responses are separate service gates.
- A generated adapter is **not** an accepted authenticated editor integration. Do not enable it automatically, mark n8n 2.44.5 as fully supported in the compatibility matrix, or reuse older hashed routes before authenticated browser acceptance.
- Enable app/router, sidebar and workflow-menu overlays separately only after the previous stage passes. Keep unrelated n8n assets native. A Vue VNode/module test does not replace a real authenticated navigation test.
- Permanent deletion, archive/restore hooks and external integrations require their own controlled behavioral tests. No provider write is implied by infrastructure validation.

Source synchronization is not a release. This maintenance task does not authorize a release tag, GitHub Release, registry image push or npm publication.
