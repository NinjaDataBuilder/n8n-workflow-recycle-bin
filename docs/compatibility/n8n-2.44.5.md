# n8n 2.44.5 validation checkpoint

Recorded on 2026-10-26. **Evidence is recorded; a full toolchain release is not approved.**

## Versions and provenance

- Recycle Bin runtime and unreleased CLI source: `0.1.8`.
- Deployed runtime source baseline: `907bd01221fee4f0761e4a262fef6be5453750ff` on the maintenance line, not the older `main` tree.

## Verified

- Recycle Bin baseline: 55 passing runtime tests. The additional seven release-gate regressions bring the current suite to **62 passing tests**.
- CLI: **7 passing tests**. This is source/packaging evidence, not approval to install on 2.44.5.
- All four 2.44.5 overlay assets were regenerated from the running editor's fingerprint-checked native assets. Generated bytes match the active sidecar and both public URL prefixes exactly.
- Public editor, sidecar page, readiness and sidecar health returned HTTP 200. The anonymous Recycle Bin API returned HTTP 401 as expected.
- Community nodes and credentials loaded in all three n8n roles. Guard probes against the bundled n8n SDK made zero provider requests. These probes are SDK-context checks, not workflow executions.
- A real, unpinned Meta Ads Management workflow blocked the operation with `write_executed=false`.
- A real, unpinned Baserow Schema Admin workflow successfully listed existing table metadata. No schema or row was changed.
- Runtime JavaScript/assets from the three community packages matched the locally built artifacts: 16 GTM files, 16 Meta files and 4 Baserow files.

## Explicitly not approved

- GTM's real read-only workflow stopped because its OAuth credential requires reconnection.
- Meta Ads Management's bounded GET stopped with provider code `190`, subcode `463`: its token expired. This is not evidence of an n8n loader incompatibility.
- Authenticated sidebar, embedded panel, navigation/reload/back and workflow flyout acceptance remain pending. One saved-vault login was rejected; no retries, password resets or authentication bypass were attempted.
- The CLI and runtime preflight still reject 2.44.5. Their allow-lists and release-bundle support metadata have deliberately **not** been broadened before the authenticated UI gate.
- No new npm package, GHCR image, GitHub Release, tag or production deployment is authorized by this checkpoint. Existing release notes and support claims must not be interpreted as a new 2.44.5 release.
